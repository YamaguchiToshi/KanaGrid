# KanaGrid — 高視認性 AAC 文字盤 Web アプリ

発話や書字に困難があるユーザー（学齢期の児童・生徒を含む）向けの、高視認性・高一瞥性を備えたオフライン対応カスタム文字盤型AAC（拡大・代替コミュニケーション）Webアプリケーションです。

**アプリ：<https://yamaguchitoshi.github.io/KanaGrid/>**

## 使い方（iPad）

1. iPad の Safari で上の URL を開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. ホーム画面のアイコンから起動します。一度開けば、機内モードなどのオフライン環境でも使えます。

横置きでの利用を想定しています。設定画面は、誤操作を防ぐため右上の設定ボタンを **3回続けてタップ** すると開きます。

### データの保存とアクセス解析について

設定・ユーザー辞書・学習データ・入力した文章は、すべて **その端末のブラウザ内（localStorage / sessionStorage）だけ** に保存され、外部サーバーへ送信されることはありません。ユーザー辞書は設定画面から CSV で書き出し・読み込みができます。

公開版では、利用状況の把握のために Cookie を使わないアクセス解析（Cloudflare Web Analytics）を利用しています。計測されるのはページ閲覧数などの統計情報のみで、入力した文章や辞書・設定の内容が送信されることはありません。オフライン環境でもアプリの動作には影響しません。

### 更新について

新しい版が公開されると、次にアプリを開き直したときに切り替わります。会話の途中で画面が勝手に再読み込みされることはありません。すぐに更新したいときは、設定画面の「今すぐ更新する」を押してください（入力中の文章は残ります）。

## 主な特徴

1. **高視認性 Material Design 3 UI ＆ 動的フォントスケーリング**
   * CSS Container Queries（`cqmin` / `cqh` / `cqw`）により、文字キー・予測候補・メッセージ欄が枠線と干渉せず最大サイズで描画されます。
   * **ライト（明背景・黒文字）** と **ダーク（暗背景・白文字）** の2テーマを即時切替可能。
   * iPadOS スタンドアロン表示時の上下システム領域（ステータスバー・ホームインジケータ）のブラー干渉を回避するセーフマージン設計。
2. **文部科学省「学年別漢字配当表」連動の8段階レベル調整**
   * 設定から **「かな / 小1 / 小2 / 小3 / 小4 / 小5 / 小6 / 一般」** の8段階を選択可能。
   * 選択した学年に応じて **「表示される漢字の学年」** と **「予測候補に出る語彙の難易度」** が同時に連動します。
   * **「かな」設定時**：漢字だけでなく外来語等のカタカナ語も含めてすべてひらがな表記に統一（例：`といれ`、`てれび`）。
   * **複合語の形態素別学年表記**：2字熟語（`電気`、`給食` 等）は交ぜ書きを防いで一括判定しつつ、複合語（`保健室`、`時間割` 等）は構成要素ごとに学年判定を行います（例：小2設定では `ほけん室`、`時間わり`）。
3. **文脈考慮ワードプレディクション ＆ ユーザー固有の共起・シーケンス学習**
   * **約15,380語の内蔵辞書**：国立国語研究所「教育基本語彙データベース・日本語教育基本語彙データベース（`brfvep`）」をベースに、学齢期の学校生活語彙とAACコア語彙・頻出活用形を統合。
   * **確定直後の文脈サジェスト**：単語を確定した直後（読み0文字）に、直前語の品詞と意味カテゴリ（身体・飲食・場所・機器・人・時間）から後続しやすい助詞・述語を自動提示し、空白を挟まずに連続して文を組み立てられます。
   * **ユーザー学習（オフライン永続化）**：単体頻度（Unigram）、直前1語（Bigram）、助詞跨ぎ2語（Trigram）、および同一文内の自立語共起（Co-occurrence）を `localStorage` に学習します。
   * **ユーザー辞書編集＆CSVインポート・エクスポート**：設定画面（誤操作防止のため**設定ボタンのトリプルタップ**で起動）から固有名詞やよく使うフレーズを登録・編集・削除可能。Excel や Numbers 等で編集しやすい CSV 形式（`読み,表記,種類`、UTF-8 BOM 付き書き出し／Shift_JIS 自動判別読み込み）でのインポート・エクスポートに対応しています。
4. **全モード11列×5行統一キーボード ＆ 初歩の算数・大文字小文字キートップ切替**
   * ひらがな・カタカナ・ABC（数字・算数記号）の全モードを **11列×5行（55マス）** に統一し、モード切替時もキーサイズと左端制御列（BS、`小゛゜` / `A→a`、空白、全消去、🌐切替）の位置が固定されます。
   * ABCモードには `0〜9` に加え、初歩の算数に対応する演算子・記号（`+` `-` `×` `÷` `=` `(` `)` `<` `>` `%`）を配置し、数式の読み上げ（「3 たす 5 イコール 8」等）やキートップの大文字・小文字切替（`A〜Z` ⇔ `a〜z`）に対応しています。
5. **表示文字列と音声読み上げ文字列の分離（Web Speech API）**
   * 画面表示が「かな」や「低学年漢字」（例：`きょうはほけん室にいきたい`）であっても、音声合成エンジンには標準的な漢字交じり表記（`今日は保健室に行きたい`）を渡すことで、自然で正確な高低アクセント・助詞発音を実現しています。数字・記号押下時も日本語音声合成エンジンで発声されます。

詳しい仕様は [SPEC.md](./SPEC.md) を参照してください。
